Telegram Movie Finder

A personal, non-commercial Python Telegram bot for discovering movies.

The bot uses The Movie Database (TMDB) API to display movie titles, posters, release dates, ratings, descriptions, and available legal streaming-provider information.

Features

Movie search by title

Movie posters and details

Multiple-language movie discovery, including Malayalam, Tamil, Telugu, Hindi, and English

Legal streaming-provider links where available

The bot does not host or distribute movie files. This project is for learning and personal use.
